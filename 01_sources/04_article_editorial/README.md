# Редакционные исходники статьи

Исходная отклоненная рукопись и редакционный PDF сохранены без изменений в локальном игнорируемом каталоге `11_backups/article_1_evidence_private/editorial`. Публичный реестр содержит только SHA-256, тип документа и относительный приватный локатор. Контакты и содержимое оригиналов в репозиторий не публикуются.

Файлы проверки, выполненной сторонним проектировщиком, и подписанное заключение эксперта находятся у автора и могут быть представлены редакции по запросу. В текущей рабочей среде они не инспектировались, поэтому их статус обозначен как подтвержденный автором, а не проверенный исполнителем.
