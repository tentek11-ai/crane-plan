# Обработанные данные

Здесь хранятся структурированные данные, полученные из оригинальных источников: реестры научных статей, ППРк, каталогов кранов и нормативных правил.

Численные нормативные ограничения допускаются в расчётное ядро только после фиксации документа, действующей редакции и точного пункта в `regulations/regulation_registry.csv`.
