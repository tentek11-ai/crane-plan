# КранПлан 2.0.2

Исправляющий выпуск для заполнения карточки объекта и других текстовых полей.

## Что добавлено

- Вставка из Word, браузера и других программ сочетанием `Ctrl+V`.
- Работа сочетаний при русской и английской раскладке клавиатуры.
- Команды `Ctrl+C`, `Ctrl+X`, `Ctrl+A`.
- Контекстное меню по правой кнопке мыши.
- Безопасное преобразование переносов строк в пробелы при вставке в однострочные поля.

## Проверка

Интерфейсные тесты воспроизводят вставку русского многострочного текста из системного буфера, а также выделение, копирование, вырезание и повторную вставку. Полный комплект из 72 автоматических тестов проходит успешно.
