# КранПлан 2.0.3

Исправляющий выпуск расчёта точек подачи грузов.

## Новая логика

- Для запуска расчёта достаточно нанести минимум одну точку подачи.
- Не требуется создавать отдельную точку для каждого активного груза.
- Груз без собственной точки проверяется на всех имеющихся точках подачи по вылету, грузоподъёмности, высоте крюка, опасной зоне и маршруту.
- Все подъёмы такого груза включаются в календарный расчёт.
- В результатах и ППРк выводится предупреждение о применённом консервативном допущении.

Если для груза позже будет нанесена отдельная точка, программа автоматически перейдёт к точной привязке этого груза.

## Проверка

Проверены два противоположных случая: допустимый груз без точки успешно рассчитывается и полностью входит в баланс подъёмов; недопустимо тяжёлый груз без точки отклоняет вариант по паспортной грузоподъёмности. Полный комплект из 73 автоматических тестов проходит успешно.
