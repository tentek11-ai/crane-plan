# КранПлан 1.5.1

Версия устраняет риск удара стрелы нижнего крана о башню верхнего.

- Для каждого крана выбирается минимальная достаточная длина стрелы.
- Обычный шаг секций - 5 м; нестандартный паспортный максимум сохраняется как конечная конфигурация.
- Длина нижней стрелы ограничивается расстоянием между осями минус 7 м: 5 м рабочего зазора и 2 м защитного габарита башни.
- Проверяются точки подачи, весь контур здания, разгрузка и складирование.
- Пара кранов не принимается, если укороченная нижняя стрела не может выполнить назначенные операции.

Расчёт остаётся предварительным и перед выпуском ППРк должен быть сверен с паспортом крана и фактической башенной комбинацией.
