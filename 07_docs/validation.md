# Валидация

## Наборы

- `PPRK-001` — `PPRK-004`: REFERENCE, используются для понимания инженерной логики и тестирования отдельных функций.
- `PPRK-005` — `PPRK-008`: VALIDATION, исходные решения скрываются от алгоритма до завершения расчёта.

## Порядок validation case

1. Подготовить только входные данные, доступные будущему пользователю.
2. Не передавать исходную модель и позицию крана.
3. Получить до трёх вариантов.
4. Сравнить с реальным ППРк по количеству кранов, моделям, позициям, высоте, стреле, критическим грузам, сроку и ограничениям.
5. Зафиксировать причины различий; совпадение с ППРк не является единственным критерием правильности.

## Автоматические тесты расчётного ядра

- точки на границе радиуса;
- интерполяция/ступени грузовой характеристики;
- масса оснастки;
- недостаточная высота;
- запретная позиция башни;
- неполное покрытие;
- конфликт двух кранов;
- выход опасной зоны;
- повторяемость результата после сохранения/загрузки.

До прохождения жёстких тестов генерация финального ППРк должна быть заблокирована.
