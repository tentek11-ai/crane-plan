## Формулы, допустимые только как кандидаты до независимой проверки

1. Любая формула из научной статьи должна быть повторно выведена, проверена размерностно и покрыта unit-тестами.
2. Нормативные расстояния и коэффициенты нельзя брать из научной статьи без проверки действующего нормативного источника.
3. Характеристики реальных моделей нельзя переносить из обзоров; источником базы должны быть каталоги производителя.
4. Результаты отдельных case study нельзя использовать как универсальные коэффициенты эффективности.
