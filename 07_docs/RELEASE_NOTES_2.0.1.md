# КранПлан 2.0.1

Исправляющий выпуск интерфейса точки подачи груза.

## Что исправлено

- На вкладке «2. План» после команды «5. Точки подачи грузов» всегда показывается отдельное поле высоты точки подачи.
- Если отметки низа котлована или верха парапета ещё не заполнены, поле остаётся пустым и доступным для ручного ввода вместо неполного открытия диалога.
- Поддержан ввод дробной высоты через точку или запятую.
- Отображаемый первый груз теперь действительно выбран по умолчанию и может быть сохранён без повторного выбора в списке.

## Проверка

Регрессионный тест воспроизводит открытие диалога при пустой общей отметке, ввод высоты `37,5` и сохранение точки подачи. Полный комплект из 70 автоматических тестов проходит успешно.
