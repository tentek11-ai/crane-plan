# КранПлан 1.6.0

Версия обновляет пользовательский интерфейс без изменения инженерной расчётной модели.

## Основные изменения

- тёмная BIM-тема в стиле Revit 2025;
- верхняя лента основных команд;
- диспетчер проекта и навигация по рабочим видам;
- отдельная панель свойств активного вида и проекта;
- синхронизация вкладок, дерева проекта и расчётного состояния;
- единое оформление форм, таблиц, холстов и предпросмотра ППРк.

Расчётные алгоритмы, проверки безопасности и формирование ППРк сохранены.
