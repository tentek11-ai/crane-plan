# КранПлан 1.5.0

Версия 1.5.0 исправляет ошибки инженерного аудита версии 1.4.0. Основной акцент сделан на безопасном отказе: программа больше не должна выдавать положительный вариант, если не доказано покрытие точек подачи, контура здания и логистических зон либо если направление работы нарушает запретную зону или защитный габарит соседней башни.

Сохранённые проекты открываются из интерфейса. Точка подачи теперь содержит назначенный груз и отметку. Стоимость рассчитывается только при подтверждённом коммерческом предложении и введённой суточной ставке.

PDF формируется с фактической сквозной нумерацией листов. Векторные исходные план и разрез внедряются без растеризации. Документ остаётся предварительным ППРк: фундамент, пристёжки, монтаж/демонтаж и окончательные паспортные башенные комбинации требуют отдельной проверки специалистом.
