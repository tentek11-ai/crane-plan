# Архитектура MVP

## Принцип

Приложение строится как автономная модульная система. Распознавание PDF не принимает инженерных решений: оно только создаёт редактируемую геометрию. Расчётное ядро работает с проверенными структурированными данными.

## Поток данных

`PDF → калибровка → геометрия → грузы → кандидаты кранов → жёсткие проверки → варианты размещения → моделирование циклов → сравнение → PDF ППРк`

## Модули

1. **Project Manager** — папка проекта, версии, профиль организации.
2. **PDF Workspace** — выбор страниц, отображение, две точки масштаба, ручное редактирование.
3. **Vector Extractor** — линии, полилинии и текст векторного PDF; результат всегда подтверждается пользователем.
4. **Site Model** — здание, граница, запретные зоны, разгрузка и склады.
5. **Load Model** — стандартные грузы, оснастка, нестандартные грузы и точки подачи грузов на здание.
6. **Crane Catalog** — модели, конфигурации стрелы, `Q(R)`, высоты, башенные системы и крепления.
7. **Feasibility Engine** — покрытие, грузоподъёмность, высота, размещение башни и опасные зоны.
8. **Placement Optimizer** — поиск вариантов для одного/двух кранов.
9. **Cycle Simulator** — количество подъёмов и календарная продолжительность.
10. **Decision Module** — Pareto-набор и ранжирование по выбранному приоритету.
11. **Report Generator** — планы, таблицы, разрез и единый PDF ППРк.
12. **Norm Registry** — правила, версии, ссылки и справка по кнопке `?`.

## Техническая граница

UI не содержит формул безопасности. Все проверки выполняются расчётным ядром с тестируемыми функциями. PDF-генератор получает только уже проверенный вариант.

## Предварительный стек

- Python для расчётного ядра и обработки PDF.
- Локальная настольная оболочка с русским интерфейсом.
- SQLite или эквивалентное локальное хранилище для каталогов и нормативных правил.
- JSON внутри папки проекта для переносимости и версионирования.
- Векторная графическая сцена для ручной разметки и перемещения кранов.

Окончательный UI-фреймворк выбирается после прототипа работы с крупными PDF на Windows 10/11 без GPU.
