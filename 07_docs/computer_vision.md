# Обработка векторного PDF

## MVP

- Извлечение векторных линий, полилиний и текстовых подписей.
- Предложение контуров здания и существующих объектов.
- Ручное подтверждение/исправление пользователем.
- Ручное задание границы площадки и запретных зон.
- Калибровка каждой страницы по двум точкам.

## Не является частью MVP

- сканированные растровые чертежи;
- полностью автоматическое семантическое понимание ППРк;
- прямой импорт DWG;
- принятие инженерных решений без подтверждения геометрии.

Критерий качества: ни один автоматически распознанный объект не становится жёстким ограничением до подтверждения пользователем.
