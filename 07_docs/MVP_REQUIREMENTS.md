# Требования к первой версии

## Цель

По векторному стройгенплану и разрезу в PDF получить до трёх проверенных вариантов установки одного или двух башенных кранов Liebherr, выбрать рекомендуемый вариант и выпустить PDF ППРк.

## Обязательные функции

| Код | Требование | Критерий приёмки |
|---|---|---|
| FR-001 | Создание, открытие и версионирование проекта | Проект повторно открывается без повторного ввода и сохраняет предыдущие версии |
| FR-002 | Загрузка страниц PDF | Пользователь выбирает стройгенплан и разрез из одного или разных файлов |
| FR-003 | Масштабирование по двум точкам | Контрольное расстояние воспроизводится с заданной точностью |
| FR-004 | Автоматический и ручной режим геометрии | Пользователь может исправить любое распознанное геометрическое ограничение |
| FR-005 | Ручная граница площадки и запретные зоны | Поиск не размещает башню в запрещённой области |
| FR-006 | Стандартные и нестандартные грузы | Массы редактируются; оснастка входит в расчётную массу |
| FR-007 | Каталог EC-B/EC-H | Для каждого решения используется подтверждённая грузовая характеристика `Q(R)` |
| FR-008 | Подбор одного или двух кранов | Возвращается не более трёх технически допустимых вариантов |
| FR-009 | Проверка полного покрытия | Каждая рабочая точка здания обслуживается хотя бы одним краном |
| FR-010 | Высотная проверка | Крюк проходит над зданием и грузом с нормативным запасом |
| FR-011 | Свободностоящий/пристёгнутый вариант | При нехватке высоты формируется вариант крепления с предлагаемыми уровнями |
| FR-012 | Совместная работа двух кранов | Проверяются пересечение, высотное эшелонирование и конфликтные зоны |
| FR-013 | Разгрузка и складирование | Строится достижимая цепочка автомобиль → разгрузка → склад → здание |
| FR-014 | Производительность | Срок объясняется количеством подъёмов, циклами, часами/сутки и коэффициентом использования |
| FR-015 | Сравнение вариантов | Таблица показывает количество кранов, модели, срок, загрузку, покрытие, ограничения и стоимость при наличии цен |
| FR-016 | Ручное перемещение крана | После изменения позиции все проверки выполняются заново |
| FR-017 | Нормативные подсказки | Кнопка `?` показывает документ, пункт, правило и ссылку |
| FR-018 | Экспорт эскиза | План выбранного варианта печатается в PDF |
| FR-019 | Формирование ППРк | Создаётся единый печатный PDF установленного состава |
| FR-020 | Контроль перед выпуском | Без подтверждения итогового экрана ППРк не формируется |

## Нефункциональные требования

- Полностью автономная работа.
- Windows 10/11, CPU-only.
- Переносной запуск из папки.
- Русский интерфейс.
- Воспроизводимость: версия исходников, каталога, норм и алгоритма сохраняется в проекте.
- Прослеживаемость: каждое число имеет источник или статус `USER INPUT`, `CATALOG`, `NORM`, `DERIVED`.
- Безопасный отказ: при недостатке данных решение не выдаётся как допустимое.
- Итоговый PDF маркируется как требующий инженерной проверки и утверждения.

## Условия успешности MVP

1. На четырёх REFERENCE cases программа воспроизводит технически допустимые решения без ручного исправления расчётного ядра.
2. На четырёх скрытых VALIDATION cases решение строится без использования исходной позиции и модели крана.
3. Ни одно нарушение грузоподъёмности, высоты, покрытия или запретной зоны не проходит как допустимый вариант.
4. Пользователь может объяснить выбор варианта по данным сравнительной таблицы.
5. Сохранённый проект повторно открывается с теми же результатами.
