# Формальная постановка

## Переменные

- `n ∈ {1,2}` — количество кранов;
- `(x_k, y_k)` — позиция крана;
- `m_k` — модель и конфигурация;
- `L_k` — длина стрелы;
- `H_k` — высота крюка;
- `R_work_k` — разрешённый максимальный рабочий вылет;
- `a_ik ∈ {0,1}` — назначение рабочей точки `i` крану `k`.

## Базовые зависимости

Для точки `i`:

`R_ik = distance((x_k, y_k), (x_i, y_i))`

`Q_required_i = Q_load_i + Q_rigging_i`

`Q_allowed(m_k, L_k, R_ik) ≥ Q_required_i`

`Σ_k a_ik ≥ 1`

`H_hook_k ≥ H_building_i + H_load_i + H_rigging_i + H_clearance_norm - H_base_k`

По п. 156(к) ФНП № 461 `H_clearance_norm = 0.5 м` над выступающими частями здания либо `2.3 м` над перекрытиями и площадками, где могут находиться люди.

Для опасной зоны приложение № 2 ФНП № 461 задаёт:

`D_danger = L_max_load + X_fall(H_fall)`

где `D_danger` откладывается от наружной крайней точки горизонтальной проекции груза, `L_max_load` — его наибольший габарит, а `X_fall` определяется таблично с линейной интерполяцией.

## Производительность

`T_cycle = T_hook + T_lift + T_trolley + T_slew + T_place + T_return`

`T_calendar = Σ(N_lift_j × T_cycle_j) / (hours_per_day × utilization)`

По умолчанию `hours_per_day = 24`, `utilization = 0.7`; оба значения редактируемы.

## Статус

Это постановка требований, а не выбранный метод решения. Возможны дискретный поиск кандидатов, MILP/CP-SAT, эвристики и локальная оптимизация. Выбор делается экспериментально после подготовки тестового набора.
