# Модель данных MVP

## Основные сущности

- `Project`: идентификатор, название, город, год, версия, статус.
- `SourceDocument`: файл, SHA-256, роль страницы, единицы, масштаб.
- `Calibration`: две пиксельные точки, реальное расстояние, коэффициент преобразования.
- `SiteBoundary`: полигон границы площадки.
- `Building`: контур, этажность, площадь этажа, секции, высота от низа котлована до парапета.
- `RestrictedZone`: тип, полигон, источник, комментарий.
- `UnloadingZone` и `StorageZone`: полигон, тип материалов, обслуживающий кран.
- `LoadType`: масса груза, масса оснастки, габариты, стандартный/пользовательский.
- `WorkPoint`: координаты, высота, требуемый груз, стадия.
- `CraneModel`: производитель, серия, модель, максимальная нагрузка.
- `CraneConfiguration`: стрела, башенная система, высота крюка, крепления, таблица `Q(R)`.
- `CranePlacement`: модель, конфигурация, координаты, максимальный рабочий вылет.
- `Scenario`: один/два крана, распределение точек, зоны и ограничения.
- `FeasibilityResult`: результаты всех жёстких проверок и причины отказа.
- `CycleEstimate`: подъёмы, длительность цикла, загрузка, календарные дни.
- `CommercialOffer`: введённые пользователем статьи стоимости.
- `NormRule`: документ, редакция, пункт, формула/значение, ссылка.
- `ReportRevision`: версия входов, алгоритма и сформированного PDF.

## Происхождение значений

Каждое инженерное число хранит `value`, `unit`, `origin`, `source_locator`, `verified_at` и `confidence`. Допустимые `origin`: `USER_INPUT`, `CATALOG`, `NORM`, `DERIVED`, `DEFAULT`.
