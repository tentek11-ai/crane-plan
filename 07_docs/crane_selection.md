# Подбор кранов

## Жёсткие условия

Для каждой рабочей точки `i` и назначенного крана `k`:

- точка достижима по радиусу;
- `Q_allowed(k, R_i) ≥ Q_load_i + Q_rigging_i`;
- высота крюка достаточна для здания, груза, оснастки и нормативного запаса;
- башня находится вне здания и запретных зон;
- максимальный рабочий вылет удовлетворяет границе зоны проноса груза;
- конфигурация башни допустима по каталогу.

## Порядок моделей

1. 130 EC-B 6.
2. 130 EC-B 8 как подтверждение резерва, если подходит 6-тонная модель.
3. Другие EC-B грузоподъёмностью 6–8 т.
4. EC-H до 12 т при недостаточности EC-B.

Сначала ищется решение с одним краном. Если его нет или пользователь выбрал приоритет скорости, строятся варианты с двумя.

## Запрет упрощения

Нельзя выбирать кран по одной максимальной грузоподъёмности. Используется полная таблица `Q(R)` конкретной длины стрелы, кратности полиспаста и высотной конфигурации.
