# Отчет о проверке выпуска

Дата проверки: 22 октября 2026 года.

## Автоматические проверки

- Контроль научных утверждений, названий трех объектов и границ верификации пройден.
- Проверка цитирования, локаторов и состава литературы пройдена.
- Проверка отсутствия персональных контактов в публичном дереве пройдена.
- Проверка структуры DOCX, таблицы, формата A4 и основных разделов пройдена.
- Проверка PDF через повторное чтение `pypdf`: 7 страниц A4, текст извлекается, внутренние идентификаторы объектов отсутствуют.

## Визуальная проверка

Финальная PDF-копия отрендерена в PNG с разрешением 144 dpi. Вручную просмотрены все семь страниц. Не обнаружены обрезанный текст, наложения, поврежденные символы, разрывы таблицы, пропавшие подписи или нарушения полей. Таблица результатов полностью помещается на странице, шапка и чередование строк читаемы, номера страниц не пересекаются с основным текстом.

Штатный DOCX-рендерер пакета Codex не смог запуститься из-за отсутствия LibreOffice в подключенном runtime; установленный Microsoft Word недоступен для COM-автоматизации из песочницы. Поэтому визуальная печатная проверка выполнена по PDF, детерминированно собранному из того же Markdown-источника и стилевого описания. DOCX дополнительно проверен структурно библиотекой `python-docx`.
