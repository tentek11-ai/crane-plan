# Переработанная статья для Инженерного вестника Дона

Каталог содержит воспроизводимую сборку статьи о математической модели допустимой области размещения башенного крана.

## Основные материалы

- `manuscript/ARTICLE_RU.md` — утверждаемая текстовая версия статьи.
- `manuscript/EDITOR_RESPONSE_RU.md` — ответ редакции по каждому замечанию.
- `results/novatorov_v222_result.json` — нормализованный результат независимого расчета версии 2.2.2.
- `results/external_validation_attestation.json` — обезличенная фиксация двух внешних ретроспективных запусков.
- `output/docx` — готовые Word-файлы статьи и ответа редакции.
- `output/pdf` — печатная PDF-копия статьи.

## Воспроизводимая сборка

```powershell
python 04_experiments/build_ivdon_article_revision.py `
  --article-root 08_dissertation/04_article_1_crane_placement `
  --output-root 08_dissertation/04_article_1_crane_placement/output/docx `
  --pdf-output 08_dissertation/04_article_1_crane_placement/output/pdf/Статья_Математическая_модель_выбора_башенных_кранов_ИВД_2026.pdf
```

Перед сборкой выполняется автоматический контроль утверждений. Он запрещает внутренние идентификаторы объектов, машинный условный статус, заявления о фактическом внедрении однокрановой схемы, экономические критерии и использование продолжительности 1,774 дня без контекста заданного набора из 160 подъемов.

## Доказательная граница

Файлы сторонних запусков, сформированные ППРк, датированная характеристика проектировщика и письменное экспертное заключение хранятся у автора и могут быть представлены редакции по запросу. Публичный репозиторий не утверждает, что непереданные оригиналы были инспектированы в текущей рабочей среде.
