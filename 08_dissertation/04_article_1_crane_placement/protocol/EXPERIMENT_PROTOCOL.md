# Замороженный протокол вычислительного исследования

Статус: утверждён автором 2026-10-20 до просмотра результатов новых расчётов.

## Предмет и единица анализа

Единица анализа — одна координата оси башенного крана для фиксированных исходных данных объекта и одной паспортной конфигурации крана. Сначала определяется допустимость; ранжирование допустимых координат является отдельной операцией.

Обязательные причины исключения: выход основания за площадку, попадание в здание или запретную зону, нарушение минимального/максимального удаления, превышение вылета, недостаток `Q(R)`, недостаток высоты, пересечение запрещённого маршрута и выход опасной зоны без подтверждённого защитного решения. Неизвестный обязательный параметр даёт `INPUT_BLOCKED`.

## Первичные показатели

- число проверенных и допустимых узлов;
- оценка площади допустимой области, м²;
- число связных компонентов;
- координата рекомендуемой точки, м;
- распределение кодов исключения;
- минимальные запасы грузоподъёмности, кг, и высоты, м;
- время вычисления, с.

Рекомендуемая точка выбирается детерминированно: максимальный минимальный запас грузоподъёмности, затем минимальный требуемый вылет, затем координаты `x`, `y` по возрастанию.

## Дискретизация и чувствительность

Предварительно зарегистрированная серия: **4 m**, **2 m**, **1 m**. Статус проектной точки должен быть одинаковым во всех трёх запусках. Между сетками 2 m и 1 m смещение рекомендуемой координаты должно быть **≤ 1 m**, изменение площади — **≤ 5%**. Порог после просмотра результата не изменяется.

## Воспроизводимость и неизменность

Каждый запуск получает уникальный Run ID, UTC-время, версию алгоритма и каталога, шаг, число уровней уточнения, SHA-256 проекта и конфигурации. Первый JSON не перезаписывается. Любое изменение входа или алгоритма требует нового Run ID. Поле `validation_status` копируется из манифеста и не может изменяться программой расчёта.

Первые два объекта имеют статус `retrospective_external_reproduction_positive`. Объект на улице Новаторов имеет статус `independent_pilot_expert_confirmed_with_conditions`: независимый программный расчет получил последующую письменную экспертную оценку с условиями безопасности. Смешанная совокупность не используется для вычисления общей «точности».
